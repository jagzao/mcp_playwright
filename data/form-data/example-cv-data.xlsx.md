# Ejemplo de archivo Excel para datos de CV

Crea un archivo Excel con estas columnas:

| nombre      | email              | telefono  | cv_path            | linkedin                    |
|-------------|-------------------|-----------|-------------------|----------------------------|
| Juan Pérez  | juan@email.com    | 555-0001  | /data/cv-juan.pdf | https://linkedin.com/in/... |
| María García| maria@email.com   | 555-0002  | /data/cv-maria.pdf| https://linkedin.com/in/... |

Guarda el archivo como `cv-datos.xlsx` en esta carpeta.

## Uso

```bash
npm run agent "Aplica a empleos usando datos de cv-datos.xlsx"
```
